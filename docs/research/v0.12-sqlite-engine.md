# V0.12 — движок SQLite: `node:sqlite` или `sql.js`

Дата: 2026-10-24. Решение: **D5 + D23** в [ARCHITECTURE.md](../../ARCHITECTURE.md#12-журнал-решений).

## Вопрос

SQLite нужно поддержать без нативных модулей (принцип 5). Варианты:

- **`node:sqlite`** — встроен в Node.js (22.13+ без флага). Работает с файлом напрямую.
- **`sql.js`** — SQLite, скомпилированный в WASM. Держит всю базу в памяти, при сохранении записывает файл целиком.

Есть ли `node:sqlite` в extension host редакторов, которые мы хотим поддерживать, и с какой версии?

## Как проверяли

Зонд [`scripts/research/sqlite-probe/probe.cjs`](../../scripts/research/sqlite-probe/probe.cjs) запускается **внутри настоящего extension host** каждого редактора (как `extensionTestsPath`) и проверяет:

- загружается ли `node:sqlite`, версия SQLite, работа в `worker_threads`;
- возможности: JSON, FTS5, `RETURNING`, оконные и математические функции, `STRICT`-таблицы;
- API: `iterate` (потоковое чтение), `setReadBigInts` (BIGINT без потери точности), `columns()` (метаданные колонок, в том числе у пустого результата), `backup`, пользовательские функции;
- вставка и чтение 100 000 строк, запись в файл и повторное открытие;
- то же для `sql.js` 1.15.1 для сравнения.

Каждый редактор запускается со своими `--user-data-dir` и `--extensions-dir`, поэтому личные профили и открытые окна не затрагиваются. Linux x64.

## Вывод

- `node:sqlite` пригоден полностью начиная с **VS Code 1.105** (октябрь 2025). Все актуальные форки (Cursor, Windsurf, Antigravity, VSCodium) уже выше.
- Гибрид с `sql.js` для старых редакторов отвергнут: два движка в поддержке и тестах, вся база в памяти (большие файлы не открыть), запись файла целиком (можно затереть изменения другой программы), нет FTS5.
- **Решение (выбрано владельцем):** `engines.vscode: ^1.105.0`, только `node:sqlite`, запуск в `worker_threads` (V1.5).
- Цели сборки берутся из `MIN_EDITOR` в `scripts/build-config.mjs`: `node22` для host и `chrome138` для webview; e2e-тесты идут на VS Code 1.105.

## Не проверено

- **Kiro** и **Trae**: версии их основы VS Code в открытых источниках не нашли. Если основа старше 1.105 — расширение там не установится, пока они не обновятся.
- Windows и macOS проверены косвенно: `node:sqlite` входит в Node внутри Electron независимо от ОС. Окончательно проверим e2e-тестами драйвера SQLite в CI на трёх ОС (V1.5).

## Как повторить

```sh
npm run build
node scripts/research/sqlite-probe/run.mjs /tmp/probe vscode@1.105.0 cursor=/usr/share/cursor/cursor
# сводка: /tmp/probe/summary.json
```

`vscode@<версия>` скачивает VS Code; `<имя>=<путь>` запускает установленный редактор (путь к исполняемому файлу Electron, не к скрипту из `bin/`).
Для сравнения с `sql.js` поставьте его временно: `npm i --no-save sql.js` — без него зонд отметит `sql.js` как недоступный.
