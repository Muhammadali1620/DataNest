# V10.1 — чек-лист паритета с оригиналом

Дата: 2026-10-31. Источник — только публичная страница расширения «Database Client» (`cweijan.vscode-database-client2`, версия 9.0.2 от 2026-07-04) в Marketplace: описание, вкладка «Feature Contributions» (имена команд, настроек и сочетаний клавиш) и «Changelog». Код оригинала не открывался. Пункты ниже — наш пересказ функций своими словами, а не тексты оригинала.

Обозначения: **есть** — у нас есть, не хуже; **частично** — основа есть, чего-то не хватает; **V10.2.x** — пробел, закрываем в этом шаге; **бэклог** — пробел, переносим (причина рядом); **не делаем** — противоречит принципам проекта.

## Итог

| | Пунктов |
|---|---|
| Есть (в том числе сделано иначе, но покрывает задачу) | 78 |

Что важно для 1.0: всё ядро клиента баз данных (подключения, дерево, редактор SQL, таблица результатов, правка данных, структура, импорт/экспорт, инструменты) после V10.2 есть целиком. В бэклоге остаются функции, которые не относятся к клиенту баз данных (Docker, FTP, S3, очереди сообщений, SSH-терминал), СУБД, для которых нет клиента без Java или нативного кода либо нет сервера для проверки, и мелочи вида таблицы.
